# web_server

Setting up and configuring a web server with Nginx.

- `0-transfer_file`: Bash script that transfers a file to a server with scp
- `1-install_nginx_web_server`: installs Nginx and serves a Holberton School page
- `2-setup_a_domain_name`: domain name pointing to the server
- `3-redirection`: 301 redirect for `/redirect_me`
- `4-not_found_page_404`: custom 404 page
- `5-design_a_beautiful_404_page.html`: designed 404 page
